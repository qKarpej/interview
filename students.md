# TASK DESCRIPTION:
Build a console application in .NET (C#) that analyzes a web page.

#### The application should:
- Accept a URL
- Read page
- Analyze web page


This task (Analyze web page) is intentionally open-ended. You can build any kind of app that takes a URL and analyzes its content. We want to see how you approach the problem, what assumptions you make, how you define the scope, and what solution you choose to build. You do not need to create a perfect or advanced product — choose a solution that matches your current skill level, and explain your decisions clearly.

# EVALUATION CRITERIA:
Functionality (40%)
- Correctly read web page and analyzes the page
- Extracts metadata and content
- Selected solution and implementation

Code Quality (20%)
- Clean and readable code
- Proper structure
- Solution explanation

Error Handling (15%)
- Handles invalid URL and HTTP errors

Completeness (10%)
- All required features implemented

Extras (15%)
